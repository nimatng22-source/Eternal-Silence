Security Policy

Overview

Eternal-Silence is committed to maintaining a safe, responsible, and trustworthy project.

Although the repository currently focuses on documentation and does not contain executable software, we take security concerns seriously.

Reporting a Security Vulnerability

If you discover a potential security vulnerability involving this repository:

1. Do not publish sensitive vulnerability details in a public issue or discussion.
2. Report the concern privately through GitHub Security Advisories, if private vulnerability reporting is available for this repository.
3. Include a clear description of the issue, its potential impact, and steps to reproduce it when possible.

If private reporting is unavailable, contact the repository maintainer through their GitHub profile without publicly disclosing sensitive details.

Our Response

We will make reasonable efforts to:

- Review submitted reports carefully.
- Acknowledge reports within seven days when possible.
- Investigate valid concerns and determine appropriate actions.
- Keep the reporter informed of significant updates when possible.

Responsible Disclosure

We ask everyone to give the project maintainers a reasonable opportunity to investigate and address reported issues before publicly disclosing them.

Scope

This policy applies to the official Eternal-Silence GitHub repository and its associated project documentation.

Thank you for helping keep Eternal-Silence safe and trustworthy.
